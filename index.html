Which ones do you need?

It depends on how you chose to have your alarms set (the app asks during setup; it's also in Settings → How alarms get set).

Recommended

A Focus filter

None needed. Everything here is optional extras.

A shortcut

One: Set Tomorrow's Alarms at a set time, or Bedtime from a Sleep Focus or charger automation.

Myself

None needed. Open the app before bed; it also sets the next 2 mornings.

Home Assistant

None for alarms. Home Assistant runs the rest with its own automations.

Not sure? Start with Set Tomorrow's Alarms: one automation, at a time you pick, every day.

How they work

Two kinds of shortcut.

🕙

At a time you choose

Set Tomorrow's Alarms runs from a Time of Day automation, for example 22:00 every day.

✉︎

When the app asks

The app sends itself a quiet notification with a command word, like RUN_BEDTIME. A Shortcuts automation that watches for that word runs the matching shortcut. Set it up once; it runs on its own after that.

Every shortcut tells the app when it started and finished, so the app can show a tick.

Setup, once per shortcut

About two minutes.

Add the shortcut. Tap its Get it button below on your iPhone. Shortcuts opens; tap Add Shortcut.

Read the note at the top. What it does, which word it watches for, and where your own steps go.

Make its automation. Shortcuts → Automation → + → Notification → App: Bedtime Bridge → Message contains: the shortcut's word, exactly → Run Immediately, Notify When Run off → Next → Run Shortcut → pick it.

Test it. In the app, tap Test it on the shortcut's card. It ticks when the app sees the shortcut ran.

Add your own steps (optional) where the shortcut says Your steps go here.

Put it in your folder (recommended): press and hold the shortcut → Move → Bedtime Bridge Shortcuts. How to make the folder.

Keep them together

One folder for all of them.

Put every Bedtime Bridge shortcut in its own folder, named Bedtime Bridge Shortcuts. Then they're easy to find when you want to add your own steps, check one, or run one by hand (Bedtime early, Good Morning on a day off).

Folders don't change how the shortcuts or their automations run.

Open Shortcuts and tap Shortcuts at the top left until you see your folders.

Tap the new folder button (top right), name it Bedtime Bridge Shortcuts, pick an icon (the moon fits) → Add.

Open All Shortcuts → Select (top right) → tap each Bedtime Bridge shortcut → Move → Bedtime Bridge Shortcuts.

Each new one you add later: press and hold it → Move → the folder.

Good to know

If something doesn't run.

More than one is fine

Every run re-checks your plan. It never sets a second set of alarms.

Check the automation

Run Immediately on and Notify When Run off, or iOS asks first. The word must match exactly, capitals included.

Notifications on

The command arrives as a notification: Settings → Notifications → Bedtime Bridge → Allow Notifications.

One app each

A shortcut works only with the app it was made for. Switched apps? Add the other version.

Never by itself

The app only opens Shortcuts when you tap a button like Get it or Test it.

Signed

The shortcuts are signed, so anyone can add them.
